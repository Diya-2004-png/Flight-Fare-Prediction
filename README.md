# ✈️ Flight Price AI Predictor

An end-to-end Machine Learning web application that predicts flight ticket prices based on travel details like airline, source, destination, date, and time.

## 🚀 Project Overview

This project focuses on building a real-world ML solution — starting from data preprocessing and model training to deployment using Flask API and frontend integration.

Users can input flight details through a simple web interface and get real-time price predictions.
